# BookletKitty
A4 boyutundaki PDF'leri veya slaytlarnızı **basılabilir kitapçık** haline getirir. Aslında **A4 PDF'leri A5 boyutunda kitap** olarak kullanmanızı sağlar.
Sağdaki releases bölümünde .exe dosyasını indirebilir ya da online çalıştırabilirsiniz.

## Booklet :  https://colab.research.google.com/drive/1cq09e424u-kZSS9QSBevfHxP1VbPi3I2?usp=sharing
- Arkalı önlü uzun kenardan çeivrmeli basılacak şekilde yazıcıya gönderilmelidir.
- Yazıcıdan çıktı aldıktan sonra elinizdeki kağıt destesini yazıcıdan çıktığı haliyle ortadan ikiyeye katlayın. 
- Orta sayfayı birbirine bantlayın . Ortasına zımba geçebilir veya delik delip iple sabitleyebilirsiniz.

 Üstteki eğer kağıtları ortadan keserseniz kestiğiniz kağıttan onları yapıştırarak kitabı ciltleyebilirsiniz fakat keserken yamukluklar yüzünden yapıştırıcı tam tutmayabiliyor bu nedenle aynı programın aynalı versiyonunu hazırladım. 

Kitabı ciltlemek isteyenler aynı şekilde kağıtları ortadan kesip kağıdın kesilmemiş kenarından yapıştırıcıyla veya delik açarak ciltleyebilir.
